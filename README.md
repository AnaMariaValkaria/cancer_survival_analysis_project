Atividade Avaliativa Individual II – Seminário e Relatório Técnico

A atividade consiste na realização individual de uma análise de sobrevivência utilizando a base de dados sorteada para cada estudante.

Cada estudante deverá escolher um tipo específico de câncer disponível em sua base, comunicar previamente a escolha ao professor e desenvolver as etapas descritas no arquivo anexado. A análise deverá incluir preparação e avaliação da qualidade dos dados, definição do tempo e do evento, métodos não paramétricos e escolha entre o modelo de Cox ou um modelo paramétrico AFT.

O link para a base de dados é o seguinte: https://drive.google.com/drive/folders/18tQs9gwT06kgNecEB2JMujiGgYC38wmS?usp=sharing. Para acessar os dados e realizar o download, você precisará utilizar seu e-mail institucional.

Deverão ser entregues:

1. Relatório técnico em PDF;
2. Código-fonte em formato .R, .Rmd ou .qmd;
3. Instruções necessárias para reprodução da análise, quando aplicável.

Os nomes dos arquivos deverão começar pelo nome do estudante. Não devem ser enviadas cópias das bases de dados.

A entrega e a apresentação ocorrerão no dia 20 de agosto de 2026. O seminário terá duração máxima de 15 minutos, seguido de arguição.
Consulte atentamente o arquivo anexado para verificar o sorteio, as etapas da análise e as orientações completas.
